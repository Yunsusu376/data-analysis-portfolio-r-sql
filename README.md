# SQL Homework (Queries Only)

This folder contains a cleaned, GitHub-friendly version of my SQL homework as query scripts only.

- `01_basic_queries.sql` — numbered solutions (Q1–Q10) with short comments.

## Data sharing note

The dataset/database used for this homework is **not included** in this repository due to data-sharing restrictions.  
Only the SQL queries are provided.

## Topics covered

- SELECT / WHERE filtering
- GROUP BY + aggregates (COUNT, AVG, MAX, SUM)
- HAVING to filter grouped results
- ORDER BY + LIMIT for ranking
- Subqueries for derived totals
- Date/time extraction (EXTRACT) for monthly aggregation

## How to use

1. Open `01_basic_queries.sql`.
2. Copy the query for the question you want.
3. Run it in your SQL environment (e.g., PostgreSQL / MySQL) against the corresponding database schema.
